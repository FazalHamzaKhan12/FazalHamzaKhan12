## 👋 About Me

I'm a **BS Computer Science student from Pakistan**, currently working toward becoming a **DevOps & Cloud Engineer**.

My interest in technology started with exploring different areas of software development. I've worked with **game development, Flutter, and web development**, but along the way I discovered something that interested me much more:

> **What happens behind the application?**

How does an application get deployed?
How does a server run it?
How do developers automate deployments?
How does infrastructure scale?
And what happens when something breaks?

Those questions led me toward **Linux, networking, cloud computing, DevOps, and automation**.

Now I'm focusing my learning on DevOps and Cloud Engineering instead of constantly switching between technologies.

---

## 🚀 What I'm Doing Now

I'm learning by **building, experimenting, breaking things, and fixing them**.

My current journey includes:

**Linux → Networking → Git → Docker → AWS → Terraform → CI/CD → Kubernetes**

I'm not trying to learn everything at once.

I'm trying to build a strong foundation and understand **how everything connects together in a real environment**.
